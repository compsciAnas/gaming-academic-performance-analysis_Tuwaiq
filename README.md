# Gaming Behavior and Academic Performance Analysis

An exploratory data analysis and clustering project examining how gaming habits, study time, and lifestyle factors relate to students' academic performance.

## Project contents

- `gaming_academic_performance_eda.ipynb` — exploratory data analysis
- `gaming_students_clustering.ipynb` — K-Means and DBSCAN clustering
- `Gaming_Academic_Performance.csv` — dataset with 8,000 student records
- `Gaming Behavior and Academic Performance EDA.pdf` — EDA report
- `Clustering_Algorithms.pptx` — clustering presentation
- `EDA_Project_Methodology.md` — project methodology

## Main findings

- Gaming time alone does not determine academic performance.
- Students who combine heavy gaming with low study time have the lowest grades.
- Heavy gamers who maintain sufficient study time perform much better.
- Study habits appear more important than gaming hours alone.

## Tools used

Python, Pandas, NumPy, Matplotlib, Seaborn, and Scikit-learn.

## Running the notebooks

1. Install Jupyter and the required Python libraries.
2. Open either notebook in Jupyter.
3. Run the cells from top to bottom.
